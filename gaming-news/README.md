# 灵境 gaming - 前端管理后台

基于 Vue 3 + Vite 构建的游戏新闻与社区平台前端管理后台。

## 技术栈

- **框架**: Vue 3
- **构建工具**: Vite
- **HTTP客户端**: axios
- **路由**: Vue Router
- **状态管理**: Pinia
- **UI**: Element Plus

## 功能页面

- 登录/注册
- 文章管理（列表、发布、编辑、删除）
- 分类管理
- 评论管理
- 用户管理
- 轮播图配置
- 数据统计（浏览量、收藏量、热度）

## 前端端口

默认运行在 `http://localhost:5173`

## 运行

```bash
# 安装依赖
npm install

# 开发环境
npm run dev

# 生产构建
npm run build
```
